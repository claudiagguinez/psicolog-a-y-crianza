# Claudia González Guíñez · Psicología y Crianza

Sitio web de una consulta psicológica online con atención individual para personas adultas y espacios grupales de acompañamiento a madres, padres y cuidadores/as de niños y niñas de 0 a 5 años.

## Enfoque

La propuesta entiende la crianza como un proceso singular. No ofrece recetas universales ni modelos rígidos: acompaña a cada persona y familia desde la escucha, la reflexión y la orientación, respetando sus circunstancias, recursos y necesidades.

## Publicación

Este sitio está preparado como web estática. Para publicarlo:

1. En GitHub, abre **Settings → Pages**.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Elige la rama **main** y la carpeta **/(root)**; guarda los cambios.
4. GitHub Pages publicará el sitio en la URL que indique esa sección.

## Antes de abrir al público

- Sustituir las imágenes de muestra por fotografías propias o con licencia adecuada.
- Completar la presentación profesional, formación, número de colegiación y datos de contacto.
- Incorporar aviso legal, política de privacidad y política de cookies conforme a la normativa aplicable.
- Revisar el tratamiento de datos personales y configurar un sistema seguro de reservas/contacto.
- El formulario actual es solo una demostración: valida los campos en el navegador, pero no envía ni almacena solicitudes. No recopila información clínica y no debe considerarse un sistema de reserva confirmado.

## Tecnologías

HTML, CSS y JavaScript sin dependencias de compilación.
